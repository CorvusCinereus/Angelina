# Angelina

基于Qt6和C++开发的安洁莉娜桌宠

## 构建

### 依赖

- [Qt6](https://qt.io/)
- C++

## 说明

### 操作说明

- 双击随机播放语音+切换动画
- 右键呼出菜单
- 按`Esc`退出，按`+`和`-`缩放桌宠

### Linux平台特殊说明

由于Wayland的限制，需要在启动后在设置菜单中启用显示边框，手动设置窗口置顶后再关闭边框显示
